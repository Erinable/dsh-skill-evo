## Builder tasks

Tasks are ordered by dependency. Each task is one independently reviewable Builder unit and includes its own acceptance checks. The first task is the thinnest end-to-end tracer bullet: one Observation stream reaches a deterministic rule resolution, Failure case, cluster, and Diagnosis.

- **Depends on:** none.
- **Requirements:** R-1, R-2, R-3, R-4, R-5, R-6, R-7, R-8, R-9, R-10, R-11.

Update `packages/skill-evolution/src/experience.ts`, `workflow.ts`, and report formatting so Failure cases, clusters, Diagnoses, and Markdown/JSON output consume resolutions, preserve PR #79 origins, and use evidence time for Diagnosis `createdAt`. Update `packages/skill-evolution/tests/evolution.spec.ts` around `:49-62`, `:89-200`, `:683-697`, and `packages/skill-evolution/tests/core.spec.ts:213-230`; keep the five non-goal-changed mappings and hand-written clustering tests unchanged, change `goal-changed` to no case plus a direct diagnosis test, and replace `upload this again` with a correction-marked fixture where the structured-origin test needs a failure.

A single Skill session containing `谢谢`, `好的`, and `继续` yields three rule resolutions and zero Failure cases. `不对，应该…`, `Please correct step two.`, `Please correct timeout diagnosis.`, `Please correct this.`, `still wrong`, and `wrong, upload this again` yield `incorrect` rule resolutions and medium content cases; `upload this again` is `unknown`. `constraint` yields low severity and boundary diagnosis. An old implicit-follow-up case without `intent` diagnoses as content. Marked topic change yields no case; a follow-up before any Skill load yields no case; explicit `satisfied` without `skill` yields no case; explicit `incorrect` remains high. For both payload and offline preceding-tool evidence, `skill-load-failed` yields composition/edit-metadata and failed `tool-result` yields tool/low/not-skill; an explicit attribution override wins. Diagnosis root cause never depends on a text substring, and two projections over unchanged events produce identical Diagnosis timestamps and ids.
