# 成员不回复时的定时升级与默认答案

提问评论必须记录目标、问题类别、默认答案和时间戳。目标成员 2 天未回复时提醒一次，4 天再次提醒并在目标不是 Decision maker 时转给 Decision maker；7 天时，可逆的业务判断按明确默认答案继续，不可逆决策、权限或花费不自动执行而置 `backlog` 等 Decision maker 安排。固定阶段避免等待无限期悬挂，又不会把缺少授权的默认值变成线上事实。

## Considered Options

- 无限期保持 `blocked` 被拒绝，因为成员暂时离线会永久阻塞后续 stage，且没有可观察的升级动作。
- 7 天后对所有问题自动采用默认答案被拒绝，因为权限、花费和不可逆决策需要明确授权。
